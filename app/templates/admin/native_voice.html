    • 
    
  • Name changes: {name} via speech_name() — shortens any new name, title + first name, not full name — works for any staff/patient

  • Count changes: number_0..number_20, number_30/40/50/100, number_many recordings per language + TTS fallback plural()

  • Place changes: place_laboratory, place_pharmacy etc per language, plus dynamic ServiceDestination.place field (per-tenant)
    • 
    
  • Voice rotation: day_of_year %4 → FEMALE1/MALE1/FEMALE2/MALE2, per org, not hardcoded to one voice
