Questions hospitals actually ask

Is this an EMR? Will it store diagnosis, vitals, prescriptions?

No. Never. Guard test fails build if such columns appear. We store only patient experience: name, phone, where they are in flow, payer policy number, assistance needs. Megalex is source of truth for money, not us. This is intentional — keeps you NDPA safe and doctors focused.

Is it multi-tenant? Can I sell to second hospital?

Yes, since day 1. Every table has org_id, RLS policies, per-tenant settings (price, building name, SLA, slots), per-tenant refs. test_rls.py proves org1 cannot see org2. Add new Organization row with slug, QR with ?h=SLUG resolves automatically. No code change.

What is tested load capacity?

Real Locust campaign: 4,000 requests/minute with 0% failures, actually served 4,462-4,482/min with headroom, p50 91ms p95 220ms. Overload 8,800/min also 0% failures, just slower (p50 230ms). Reproduce command in LOAD_TEST_REPORT.md. Honest, not hype.

What about WhatsApp and SMS costs?

Meta WhatsApp Cloud free 1000 convos/month, then ~$0.02/convo Nigeria. Termii SMS ₦3-4, Twilio SMS ~$0.05. Voice via browser Web Speech API free forever — uses phone speaker. For 100 patients/day, ~₦10k/month SMS if WhatsApp mostly.

Do I need to buy TVs?

No. Use existing TV + HDMI from laptop or Android Cast. One TV at reception, one gold TV at executive lounge if you have Fast Track. Brightness + night mode per TV, no extra hardware.

What is Fast Track MUST consent?

Patient must tick 2 boxes: privacy + "I choose Fast Track, I understand it is premium, I agree to extra fee". Backend blocks if missing. Audit logs consent_at. Staff at desk also explains verbally.
